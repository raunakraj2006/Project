## To-Do list Application

## Project Statement

The To-Do List Application is a simple python based programe made to help the users to mange their daily tasks. The user can add tasks, view the tasks, mark tasks as completed, and delete tasks when they complete it.


The program uses Python concepts such as lists, dictioaries, loops, conditional statement, functions of list methods,and user input to manage tasks.

## Feature.
1. Add a new task.
2. View all added task.
3. Mark a task as completed.
4. Delete a task.
5. Display the status of each task as pending or completed.
6. Exit the application when the user is finished.

## Technologies Used

- Programmimng Language: Python 
- Data Structure: List and Dictionary 

## Objective

The main objective of this project is to creat a simple task-management application while appliying fundamental Pyhton programming concepts in a practical project.

## How It Works

When the program starts, it displays a menu containing different options. The user selects an option by entering its corresponding number. The program then performs the selected operation and manages the task stored in the program.

Each task is stored as a disctionary containing the task name and its completion status.


## Conclusion

This project demonstrates how basic Python Concepts can be combined to creat a useful real world application. It also provids a foundation for developing a more advanced task-management application in the future.
